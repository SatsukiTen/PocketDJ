# 用語集（ユビキタス言語）— DJ App

> この用語集に定義された言葉は、仕様書・設計書・コード・会話で一貫して使用する。
> 新たな用語が生まれた場合はここに追記する。

---

## デッキ・再生

| 用語 | 定義 |
|---|---|
| **デッキ（Deck）** | 1曲を再生・操作するための仮想プレイヤー。本アプリはデッキAとデッキBの2台を持つ |
| **デッキA / デッキB** | 2つのデッキの識別名。画面左をA、右をBとする |
| **トラック（Track）** | 端末内の音楽ファイル1曲。MP3 / AAC / FLAC等 |
| **ロード（Load）** | トラックをデッキにセットして再生可能な状態にすること |
| **再生位置（Playhead）** | トラック内の現在の再生箇所。時間（秒）またはサンプル位置で表す |
| **波形（Waveform）** | トラックの音量変化を視覚化した表示。再生位置の把握に使う |

---

## テンポ・同期

| 用語 | 定義 |
|---|---|
| **BPM（Beats Per Minute）** | 1分間のビート数。テンポの単位 |
| **BPM検出（BPM Detection）** | トラックの波形を解析してBPMを自動推定する処理 |
| **Sync（シンク）** | デッキBのBPMをデッキAに合わせて自動調整する機能 |
| **ピッチ調整（Pitch/Tempo Adjust）** | 再生速度（BPM）を手動で変更するスライダー操作。±10%程度の範囲 |
| **ビートグリッド（Beat Grid）** | BPMを元にトラック内のビート位置をグリッドとして算出したもの。Syncの基準となる |

---

## ミックス・音量

| 用語 | 定義 |
|---|---|
| **クロスフェーダー（Crossfader）** | デッキAとデッキBの出力音量バランスを調整するスライダー（左端=A全開、中央=均等、右端=B全開） |
| **チャンネルフェーダー（Channel Fader）** | 各デッキ個別の音量を調整するスライダー |
| **ミックス（Mix）** | 2曲をクロスフェーダーでなめらかにつなぐ操作 |
| **ミックスポイント（Mix Point）** | 曲のつなぎ目となる再生位置。通常はビートが揃う箇所 |
| **マスター音量（Master Volume）** | アプリ全体の出力音量 |

---

## イコライザー・エフェクト

| 用語 | 定義 |
|---|---|
| **イコライザー（EQ / Equalizer）** | 音声の周波数帯域ごとの音量を調整する機能 |
| **High（ハイ）** | EQの高音域（概ね 4kHz 以上） |
| **Mid（ミッド）** | EQの中音域（概ね 500Hz〜4kHz） |
| **Low（ロー）** | EQの低音域（概ね 500Hz 以下）。ベース・キックに相当 |
| **キル（Kill）** | EQのある帯域を完全にカット（音量ゼロ）すること |

---

## ループ・サンプリング

| 用語 | 定義 |
|---|---|
| **ループ（Loop）** | トラックの指定区間を繰り返し再生する機能 |
| **ループイン（Loop In）** | ループ区間の開始点 |
| **ループアウト（Loop Out）** | ループ区間の終了点。ここに達すると Loop In に戻る |
| **ループ長（Loop Length）** | ループ区間の長さ。ビート数単位（1・2・4・8ビート等）で指定 |
| **サンプリング（Sampling）** | ループイン〜ループアウト間のフレーズを切り取り、繰り返し再生する操作 |

---

## スクラッチ

| 用語 | 定義 |
|---|---|
| **スクラッチ（Scratch）** | ターンテーブルのレコードを手で前後に動かす操作を模したエフェクト |
| **スクラッチゾーン（Scratch Zone）** | 画面上のタッチ操作をスクラッチとして入力する領域（仮想レコード盤） |
| **スクラッチ速度（Scratch Speed）** | タッチのスワイプ速度に応じて変化する再生速度の倍率 |

---

## 設定

| 用語 | 定義 |
|---|---|
| **設定画面（Settings）** | アプリの動作をカスタマイズする画面 |
| **クロスフェーダーカーブ（Crossfader Curve）** | クロスフェーダー操作時の音量変化の特性。Linear（線形）またはEqual Power（S字）から選択する |
| **Linear（線形カーブ）** | スライダー移動量に比例して音量が変化するフェードカーブ。スクラッチ・カット系向き |
| **Equal Power（S字カーブ）** | 中央付近でゆっくり、両端で急激に変化するフェードカーブ。合成音量が一定に保たれ、なめらかなミックス向き。デフォルト |

---

## ライブラリ

| 用語 | 定義 |
|---|---|
| **ライブラリ（Library）** | 端末内の音楽ファイル一覧。MediaStoreから取得する |
| **ブラウザ（Browser）** | ライブラリを閲覧・検索してデッキにロードするためのUI |
| **メタデータ（Metadata）** | トラックの曲名・アーティスト名・アルバム名・時間等の付属情報 |
