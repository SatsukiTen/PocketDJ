# UC-008: 端末内の音楽ライブラリを閲覧・検索する

| 項目 | 内容 |
|---|---|
| **ID** | UC-008 |
| **名前** | 端末内の音楽ライブラリを閲覧・検索する |
| **アクター** | ユーザー |
| **目的** | 端末内の音楽ファイルをすばやく見つけ、デッキにロードする |
| **事前条件** | アプリが起動済み。ストレージ権限が許可されている |
| **事後条件** | 選択されたトラックがデッキにロードされる（UC-001へ） |

---

## 基本フロー

1. ユーザーがデッキのロードボタンをタップする
2. システムがMediaStoreから端末内の音楽ファイル一覧を取得する
3. システムがライブラリブラウザを表示する（曲名 / アーティスト / 時間）
4. ユーザーがリストをスクロールしてトラックを探す
5. ユーザーがトラック行をタップする
6. UC-001（トラックをデッキにロードする）に遷移する

---

## 代替フロー

| 分岐 | 条件 | 処理 |
|---|---|---|
| A1 | ユーザーが検索バーに文字を入力する | 曲名・アーティスト名で前方一致フィルタリングをリアルタイムに実行する |
| A2 | ユーザーがソートボタンをタップ | 曲名順 / アーティスト名順 / 追加日順 で一覧を並び替える |
| A3 | ユーザーがブラウザ外をタップまたはバックボタン操作 | ブラウザを閉じる。デッキの状態は変化しない |

---

## 例外フロー

| 例外 | 条件 | 処理 |
|---|---|---|
| E1 | ストレージ権限が拒否されている | 権限説明ダイアログを表示し、システム設定への誘導ボタンを提示する |
| E2 | 端末内に対応音楽ファイルが存在しない | 「音楽ファイルが見つかりません」メッセージを表示する |

---

## 補足

- 対応フォーマット: MP3 / AAC（M4A） / FLAC / WAV / OGG
- ライブラリの取得はAndroid MediaStore APIを使用する
- 1000曲以上でもスクロールがなめらかに動作すること（仮想スクロール使用を検討）
