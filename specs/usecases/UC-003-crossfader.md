# UC-003: クロスフェーダーで音量バランスを調整する

| 項目 | 内容 |
|---|---|
| **ID** | UC-003 |
| **名前** | クロスフェーダーで音量バランスを調整する |
| **アクター** | ユーザー |
| **目的** | デッキAとデッキBの出力音量バランスをリアルタイムに調整し、曲をなめらかにミックスする |
| **事前条件** | アプリが起動済み |
| **事後条件** | クロスフェーダーの位置に応じた音量バランスで音声が出力されている |

---

## 基本フロー

1. ユーザーがクロスフェーダースライダーを左右にドラッグする
2. システムがスライダー位置をリアルタイムに読み取る（操作遅延: 20ms以下）
3. システムがデッキA・Bの出力音量を以下の通り変化させる：
   - 左端（0%）: デッキA = 100%、デッキB = 0%
   - 中央（50%）: デッキA = 100%、デッキB = 100%
   - 右端（100%）: デッキA = 0%、デッキB = 100%
4. ユーザーが指を離すとスライダーはその位置に固定される

---

## 代替フロー

| 分岐 | 条件 | 処理 |
|---|---|---|
| A1 | スライダーをダブルタップ | スライダーを中央（50%）にリセットする |

---

## 補足

- フェードカーブはユーザーが設定から選択できる（下記2種）：
  - **Linear（線形）**: スライダー移動量に比例して音量が変化。スクラッチ・カット系操作向き
  - **Equal Power（S字）**: 中央付近でゆっくり変化し両端で急変。なめらかなミックス向き
- 設定変更は即座に反映される（次の操作から有効）
- デフォルトは **Equal Power**
- チャンネルフェーダー（各デッキ個別の音量）はクロスフェーダーと独立して動作する
