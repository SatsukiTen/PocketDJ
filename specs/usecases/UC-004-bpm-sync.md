# UC-004: BPMを検出し、デッキ間でSyncする

| 項目 | 内容 |
|---|---|
| **ID** | UC-004 |
| **名前** | BPMを検出し、デッキ間でSyncする |
| **アクター** | ユーザー |
| **目的** | 2曲のテンポを自動的に揃え、ビートがずれない状態でミックスできるようにする |
| **事前条件** | 少なくとも1つのデッキにトラックがロード済みである |
| **事後条件** | Sync有効時、デッキBのBPMがデッキAのBPMに一致している |

---

## 基本フロー（BPM検出）

1. UC-001 でトラックがロードされる
2. システムが自動でBPM検出処理を実行する（バックグラウンド）
3. 検出完了後、デッキにBPM値（例: 128.0）を表示する

## 基本フロー（Sync）

1. ユーザーがデッキBの「SYNC」ボタンをタップする
2. システムがデッキAの現在BPMを基準値として取得する
3. システムがデッキBの再生速度を調整し、BPMをデッキAに一致させる
4. デッキBのBPM表示が更新され、SYNCボタンがアクティブ状態（点灯）になる
5. デッキAのBPMが変化した場合、デッキBのBPMも追従して変化する

---

## 代替フロー

| 分岐 | 条件 | 処理 |
|---|---|---|
| A1 | デッキAにトラックがロードされていない | SYNCボタンを無効化（グレーアウト）して操作不可にする |
| A2 | BPM検出が失敗（検出不能なトラック） | BPM表示を「--.-」とし、Syncは無効にする。手動ピッチ調整は可能 |
| A3 | ユーザーが再度SYNCボタンをタップ | Syncを解除する。デッキBのBPMは解除時点の値のまま固定される |

---

## 補足

- BPM検出精度: ±0.5 BPM以内を目標とする（60〜200 BPMの範囲）
- ピッチ調整範囲: ±16%
- Sync中もユーザーがピッチスライダーを操作した場合、Syncは自動解除される
