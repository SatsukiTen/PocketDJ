# AC-003: クロスフェーダーで音量バランスを調整する

対応ユースケース: UC-003

---

## AC-003-01: 左端（デッキAのみ出力）

```
Given  デッキA・Bが共に再生中である
When   クロスフェーダーを左端に移動する
Then   デッキAの音声のみ聴こえる
And    デッキBの音声は聴こえない
```

## AC-003-02: 右端（デッキBのみ出力）

```
Given  デッキA・Bが共に再生中である
When   クロスフェーダーを右端に移動する
Then   デッキBの音声のみ聴こえる
And    デッキAの音声は聴こえない
```

## AC-003-03: 中央（均等ミックス）

```
Given  デッキA・Bが共に再生中である
When   クロスフェーダーを中央に移動する
Then   デッキAとデッキBが同じ音量で聴こえる
```

## AC-003-04: リアルタイム応答

```
Given  デッキA・Bが共に再生中である
When   クロスフェーダーをドラッグ操作する
Then   操作から 20ms 以内に音量バランスが変化する
```

## AC-003-05: ダブルタップリセット

```
Given  クロスフェーダーが右端に移動している
When   クロスフェーダーをダブルタップする
Then   クロスフェーダーが中央位置にリセットされる
```

## AC-003-06: フェードカーブ切替（Linear）

```
Given  設定画面でクロスフェーダーカーブを「Linear」に変更する
When   クロスフェーダーを左端から右端へ一定速度でドラッグする
Then   デッキAの音量が一定の割合で線形に減少する
And    デッキBの音量が一定の割合で線形に増加する
```

## AC-003-07: フェードカーブ切替（Equal Power）

```
Given  設定画面でクロスフェーダーカーブを「Equal Power」に変更する
When   クロスフェーダーを中央に置く
Then   デッキA・Bそれぞれの音量が約 71% である
And    合成後の知覚音量が左端・右端と同等に保たれる
```

## AC-003-08: デフォルトカーブ

```
Given  アプリを初回起動する
When   設定画面のクロスフェーダーカーブ設定を確認する
Then   「Equal Power」が選択されている
```

## AC-003-09: 設定変更の即時反映

```
Given  クロスフェーダーが中央にある状態でカーブを切り替える
When   設定画面でカーブを「Linear」から「Equal Power」に変更する
Then   次のクロスフェーダー操作から新しいカーブが適用される
```
