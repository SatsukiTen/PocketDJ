# AC-002: デッキを再生・一時停止・停止する

対応ユースケース: UC-002

---

## AC-002-01: 再生開始

```
Given  デッキAにトラックがロード済みで停止中である
When   再生ボタン（▶）をタップする
Then   音声の再生が開始される
And    再生位置インジケーターが動き始める
And    ボタン表示が ⏸ に変わる
```

## AC-002-02: 一時停止

```
Given  デッキAが再生中である
When   一時停止ボタン（⏸）をタップする
Then   音声が停止する
And    再生位置インジケーターが停止する
And    ボタン表示が ▶ に変わる
```

## AC-002-03: 一時停止後の再開

```
Given  デッキAが一時停止中で、再生位置が 1:30 である
When   再生ボタン（▶）をタップする
Then   1:30 の位置から再生が再開される
```

## AC-002-04: 停止

```
Given  デッキAが再生中または一時停止中である
When   停止ボタン（⏹）をタップする
Then   音声が停止する
And    再生位置インジケーターが 0:00 に戻る
```

## AC-002-05: トラック末尾到達

```
Given  デッキAが再生中である
When   トラックの末尾まで再生が完了する
Then   再生が自動停止する
And    ボタン表示が ▶ に変わる
And    再生位置は末尾のまま保持される
```
