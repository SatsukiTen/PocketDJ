# AC-005〜007: EQ・ループ・スクラッチ

---

# AC-005: イコライザー

対応ユースケース: UC-005

## AC-005-01: Low キル

```
Given  デッキAが再生中で、Low EQが 0dB である
When   Low EQノブを最小（-∞）まで下げる
Then   低音域（ベース・キック）が消える
And    高音域・中音域は変化しない
```

## AC-005-02: ダブルタップリセット

```
Given  High EQが +6dB に設定されている
When   High EQノブをダブルタップする
Then   High EQが 0dB にリセットされる
```

## AC-005-03: デッキ独立性

```
Given  デッキAのLow EQをキルしている
When   デッキBのLow EQを確認する
Then   デッキBのLow EQは 0dB（変化なし）である
```

# AC-006: ループ再生

対応ユースケース: UC-006

## AC-006-01: ビート数指定ループ

```
Given  デッキAが128BPMのトラックを再生中である
When   4ビートループボタンをタップする
Then   現在位置から約1.875秒（4ビート分）のループ区間が設定される
And    ループ区間のリピート再生が開始される
And    波形上にループ区間がハイライト表示される
```

## AC-006-02: ループ解除

```
Given  デッキAがループ再生中である
When   ループボタンを再度タップする
Then   ループが解除される
And    通常再生がループアウト位置から継続される
```

# AC-007: スクラッチ

対応ユースケース: UC-007

## AC-007-01: 順方向スクラッチ

```
Given  デッキAにトラックがロードされている
When   スクラッチゾーンで指を前方に素早くスワイプする
Then   トラックが通常より速い速度で再生される
And    操作から 20ms 以内に音声が変化する
```

## AC-007-02: 逆方向スクラッチ

```
Given  デッキAにトラックがロードされている
When   スクラッチゾーンで指を後方にスワイプする
Then   トラックが逆再生される
```

## AC-007-03: スクラッチ解除

```
Given  スクラッチゾーンを操作中（再生中だった）である
When   指をスクラッチゾーンから離す
Then   通常の再生速度・方向に戻る
```
