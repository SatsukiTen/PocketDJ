# AC-001: トラックをデッキにロードする

対応ユースケース: UC-001

---

## AC-001-01: 正常ロード

```
Given  端末内にMP3ファイルが存在し、ストレージ権限が許可されている
When   デッキAのロードボタンをタップし、ライブラリからトラックを選択する
Then   デッキAに曲名・アーティスト名が表示される
And    再生位置が 0:00 になっている
And    波形が表示されている
And    BPM値が表示されている（検出成功時）
```

## AC-001-02: ストレージ権限未許可

```
Given  ストレージ権限が拒否されている
When   ロードボタンをタップする
Then   権限リクエストダイアログが表示される
```

## AC-001-03: 非対応フォーマット

```
Given  端末内に非対応フォーマットのファイルが存在する
When   そのファイルをライブラリで選択する
Then   「このファイルは再生できません」のエラーメッセージが表示される
And    デッキの状態は変化しない
```

## AC-001-04: 再生中デッキへの上書きロード

```
Given  デッキBが再生中である
When   デッキBに別のトラックをロードする
Then   デッキBの再生が停止する
And    新しいトラックがロードされ、再生位置が 0:00 になる
```
