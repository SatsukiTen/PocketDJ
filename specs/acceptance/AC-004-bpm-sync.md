# AC-004: BPM検出・Sync

対応ユースケース: UC-004

---

## AC-004-01: BPM自動検出

```
Given  128 BPMのトラックが存在する
When   そのトラックをデッキにロードする
Then   5秒以内にBPMが表示される
And    表示されたBPMが 127.5〜128.5 の範囲内である（±0.5 BPM精度）
```

## AC-004-02: Sync有効化

```
Given  デッキAに128BPMのトラック、デッキBに140BPMのトラックがロードされている
When   デッキBのSYNCボタンをタップする
Then   デッキBのBPM表示が 128.0 になる
And    SYNCボタンがアクティブ（点灯）状態になる
```

## AC-004-03: Sync中のBPM追従

```
Given  デッキBがSYNC有効状態である
When   デッキAのピッチスライダーを操作してBPMを 132 に変更する
Then   デッキBのBPMも 132 に追従する
```

## AC-004-06: ピッチ調整範囲

```
Given  デッキAに128BPMのトラックがロードされている
When   ピッチスライダーを最大に操作する
Then   BPMが 148.48（+16%）を超えない
When   ピッチスライダーを最小に操作する
Then   BPMが 107.52（-16%）を下回らない
```

## AC-004-04: Sync解除

```
Given  デッキBがSYNC有効状態である
When   デッキBのSYNCボタンを再度タップする
Then   SYNCボタンが非アクティブになる
And    デッキBのBPMはSync解除時点の値で固定される
```

## AC-004-05: BPM未検出時のSync不可

```
Given  デッキAにBPM未検出のトラックがロードされている
When   デッキBのSYNCボタンを確認する
Then   SYNCボタンがグレーアウトして操作不可である
```
